LexiC — plataforma terminológica em produção

LexiC — terminological platform in production

Sistema web completo desenvolvido para o grupo de pesquisa LexiC da Universidade de Brasília, coordenado pela Profa. Dra. Flávia de Oliveira Maia Pires.

A plataforma centraliza glossários terminológicos, gestão de corpus e acesso público a dados linguísticos — ferramenta ativa de pesquisa, não demonstração.

Registro de software em processo pelo CDT/UnB (INPI). O código permanece privado; o produto é público.

A complete web system developed for the LexiC research group at the University of Brasília, coordinated by Prof. Dr. Flávia de Oliveira Maia Pires.

The platform centralizes terminological glossaries, corpus management, and public access to linguistic data — an active research tool, not a demonstration.

Software registration in progress through CDT/UnB (INPI). The code is private; the product is public.
